Pagina sencilla para la clase de Diseño de sistema en  Internet 

Contenido de la página
- Encabezado principal (`<h1>`) y subtítulos (`<h2>`, `<h3>`, `<h6>`)
- Párrafo de presentación (`<p>`)
- Listas de productos, habilidades y enlaces (`<ul>`, `<li>`)
- Una imagen (`<img>`), enlaces externos (`<a>`) y un vaso de leche interactivo con JavaScript

Estructura del proyecto
```
Guia frontend/
├── index.html
├── styles.css
├── pinos.svg
└── README.md
```

Cómo ver la página
1. Descarga o clona el repositorio.
2. Abre el archivo `index.html` en tu navegador.
